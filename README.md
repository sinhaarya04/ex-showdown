## 🎰 What This Is

The landing site for **E[X] Showdown** — an algorithmic poker tournament run by the E[X] Prediction Markets club at Northeastern. Students don't play poker; **their code does**. You write a Python bot, submit it, and it battles other students' algorithms hand after hand.

## 🖥️ The Site

- [`index.html`](index.html) — tournament landing page: format, rules, signup
- [`about.html`](about.html) — about E[X] and the event

Pure static HTML/CSS with a **terminal-green hacker aesthetic** (`Share Tech Mono`, `#00ff41` on black) — no build step, no dependencies, deploys anywhere.

## 🚀 Run Locally

```bash
python3 -m http.server 8000
# → http://localhost:8000
```
